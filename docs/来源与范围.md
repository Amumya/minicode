# 来源与范围

## 参考的项目

| 项目 | 用来做什么 | 许可证 |
|---|---|---|
| [learn-claude-code](https://github.com/shareAI-lab/learn-claude-code) | 拆解学习，s01 到 s17 | 见上游 |
| [mini-swe-agent](https://github.com/SWE-agent/mini-swe-agent) | 对照用的最小实现 | MIT |

两个项目的源码都没有复制进这个仓库。文档里提到它们的实现时用 `文件:行号`
指过去，读者自己去上游看。

之前那一版项目把参考源码下载到本地读，已经归档不用了，也没有发布。
这一版改成只引用、不复制。

## 自己写的部分

| 路径 | 内容 |
|---|---|
| `src/minicode/` | 包本体，目前只有骨架 |
| `tests/` | 自检，不需要 API key |
| `eval/` | 评测，还没开始建 |
| `tools/push_to_github.py` | 上传脚本，走 GitHub REST API |
| `docs/` | 环境记录和这份说明 |

## 不做的

- 不去追 Claude Code、Cursor 那些产品的功能
- 不碰模型训练和微调，这个项目考的是工程和治理
- 不一开始就支持一堆语言生态，先把范围控住

## 前一版留下的东西

前一版项目（已归档）里攒了十几条实测记录，比如 Anthropic 兼容端点该填哪个
路径、Windows 下 shell 语法怎么处理、权限判定从子串匹配改成结构化解析、
隐藏测试和只读约束怎么做。

这些现在都当作待验证的假设，不是结论。新实现写完之后逐条重测，测过的才
写进 `docs/取舍与证据.md`。
