# 环境实测

2026-11-13 在这台 Windows 机器上测的。

这台机器网络比较特殊，而且隔一段时间就变。写下来是为了下次跑不起来的时候先对一遍，别先去怀疑代码。

## 根因：IPv6 是黑洞

一开始我以为 npm、清华 PyPI、git 协议"都不通"。实测发现根因只有一个：

```
registry.npmjs.org   默认 200 / 7.67s    仅 IPv4 200 / 0.71s    仅 IPv6 000 失败
registry.npmmirror   默认 200 / 7.23s    仅 IPv4 200 / 0.15s    仅 IPv6 000 失败
```

DNS 先返回 IPv6，IPv6 连不上，要卡 7 秒左右才回退到 IPv4。我之前的检测超时设的是 8 秒，正好把"能通但要 7 秒"误判成"不通"。

所以处理办法是**优先用 IPv4**，不是"找能通的镜像"。

## 现在的配置

| 项 | 配置 |
|---|---|
| Node/IPv4 | `NODE_OPTIONS=--dns-result-order=ipv4first`（用户环境变量，新终端生效）|

### 注意：git 依赖代理，而且代理不稳定

git 走的是本地代理，**代理客户端必须开着**。关掉的话 git 会失败，npm 不受影响。

更要紧的是**代理的 TLS 握手是随机失败的**，实测数据：

```
fetch 三次：失败 / 失败 / 成功
push  三次：成功 / 成功 / 失败
```

错误长这样（两种后端都试过，都会挂）：

```
OpenSSL SSL_connect: SSL_ERROR_SYSCALL in connection to github.com:443
schannel: failed to receive handshake, SSL/TLS connection failed
```

差别只在 TLS 后端，不在 fetch 还是 push —— 两边都随机挂。用 `GIT_CURL_VERBOSE=1` 看，
代理隧道能建起来（`CONNECT` 返回 200），卡在后面的 TLS 握手。

因为大约三次才能成一次，所以用 `tools/git_push.py` 提交和推送，它会自动重试：

```powershell
.venv\Scripts\python.exe tools\git_push.py -m "改了什么"
```

想撤掉代理配置：

```powershell
git config --global --unset http.https://github.com/.proxy
```

想彻底不依赖代理，可以在网卡上关掉 IPv6（需要管理员权限，影响全局）。没试过，
因为代理已经够用，而且 IPv6 那件事和代理这件事是两个独立的问题。

## 上传脚本的局限（重要）

`tools/push_to_github.py` 是走 GitHub REST API 的上传脚本，在 git 协议不通的时候救过急。它有一个**已知缺陷**：

> 用 `base_tree` 增量更新，只能覆盖和新增文件，**不能删除文件**。

后果是本地删掉的文件在 GitHub 上会一直留着。实测踩到过：`tools/run_task.py` 明明在阶段 C 就删了，远端一直还在，直到后来换成真 git 才发现。

现在 git 能用了，正常提交都走 `git commit` + `git push`。这个脚本留着当后备。

## 踩过的坑

| 坑 | 表现 | 怎么处理 |
|---|---|---|
| pip 装不上留垃圾 | 根目录多出 `pip-build-env-*`、`pip-install-*`、`pip-ephem-wheel-cache-*`，被提交进去了 | `.gitignore` 加 `pip-*/` |
| 空仓库建不了 blob | `POST /git/blobs` 返回 409 Git Repository is empty | 先用 Contents API 写个 README 把对象库建起来 |
| 空仓库查 ref 返回 409 不是 404 | 按 404 写的容错没生效 | 两种都容忍 |
| pytest 临时目录落到仓库根 | 差点被提交 | `.gitignore` 加 `pytest-of-*/` |
| 子进程超时杀不干净 | 评测卡死十几分钟，孤儿 python 烧 CPU | `taskkill /F /T`，见取舍记录 D8 |

# 推代码
git add -A
